## Технические различия

- Google Cloud заменён на BotHost в обозначении вычислительного сервера согласно исходному заданию. Drive — отдельный OAuth-получатель. Статусы и ограничения реальные.
- «Автоудаление из облака» подписано «Автоудаление с сервера»: удаляются подтверждённые локальные данные BotHost, а не переданные Drive-файлы.
- После подключения API доступ к Google Drive находится в «Облако → Автосинхронизация»: если Drive ещё не авторизован, откроется существующий технический OAuth sheet. Новая строка Google Drive в Настройки не добавляется.
- Поля API имеют понятные подписи HTTPS-адреса и ADMIN_API_TOKEN вместо фиктивных Project ID/API key Google. Сохраняется композиция исходного sheet. SAF picker и OAuth/системные разрешения рисует Android.
- Размеры показываются десятичными КБ/МБ/ГБ/ТБ; дисковый лимит вычисляется по-прежнему в байтах, 10 ГиБ = 10737418240.

## Новые элементы и состояние функций

Новые пункты не пропущены из-за демонстрационного поведения HTML:

- Проверка целостности — включена постоянно: libtorrent проверяет pieces, Drive-передача сверяется по размеру и MD5. Отключение не предлагается фактически.
- Автораспаковка .zip/.rar — показана выключенной; нажатие сообщает, что сервер не поддерживает операцию. Автораспаковки в scheduler нет.
- Лимит мобильного трафика — показан «Без лимита»; реализация счётчика/суточного ограничения пока отсутствует. Ограничение Только Wi-Fi работает отдельно.
- Ночной режим — выключен; нажатие сообщает об отсутствии расписания. Фиктивной смены переключателя нет.
- Защита приложения — выключена; biometric/PIN gate пока не реализован. Keystore защищает секреты, но не считается блокировкой входа.

Это перенос дизайна с сохранением существующих рабочих функций, а не заявление о реализации новых backend-возможностей HTML.
